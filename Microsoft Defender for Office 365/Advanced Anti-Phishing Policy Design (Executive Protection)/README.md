# 🛡️ Defender for Office 365 — Advanced Anti-Phishing Policy Design (Executive Protection)

## 📌 Overview
This lab demonstrates how to design and deploy advanced anti-phishing protections in Microsoft Defender for Office 365,
with a focus on protecting executive and high-value accounts from impersonation-based attacks.

## 🎯 Learning Objectives
- Configure advanced anti-phishing policies
- Protect executive users from impersonation attacks
- Enable spoof intelligence and mailbox intelligence
- Understand phishing policy precedence and enforcement

## 🧰 Tools & Services Used
- Microsoft Defender for Office 365
- Microsoft 365 Defender Portal
- Exchange Admin Center
- PowerShell (Exchange Online)

## 🏗️ Lab Structure
- Design anti-phishing policy
- Configure impersonation protections
- Assign policy to executive users
- Validate detection and response

## 📝 Summary of Steps
- Create advanced anti-phishing policy
- Enable impersonation and spoof detection
- Assign policy to VIP users
- Validate using simulated phishing

## ✅ Expected Outcome
Executive users are protected by advanced anti-phishing policies that detect and remediate impersonation-based threats.

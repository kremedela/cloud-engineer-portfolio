# Automated Report Generator in Python

## 🎯 Objective
Learn to collect, process, and generate PDF reports automatically from CSV datasets using Python. This simulates real-world reporting automation in enterprise environments.

## 🧰 Key Skills
- Python Automation
- Data Processing with Pandas
- Data Visualization with Matplotlib
- PDF Report Generation with ReportLab

## 📁 Folder Structure
- **docs/** – detailed lab steps  
- **scripts/** – Python scripts to run the lab  
- **data/** – sample CSV data  
- **charts/** – generated charts  
- **reports/** – generated PDF reports  

## 📝 Prerequisites
- Python 3.8+ installed  
- `pandas`, `matplotlib`, `reportlab` Python packages (`pip install pandas matplotlib reportlab`)  
- Sample CSV data in `data/` folder  

## 🧪 Lab Steps (Summary)
1. Load sample CSV data  
2. Process data and generate summary statistics  
3. Visualize data with charts  
4. Generate a PDF report with charts and summary  
5. (Optional) Automate with Python script  

## ✅ Expected Outcome
- A PDF report with data summary and charts is generated in `reports/`  
- Charts are saved in `charts/`  
- Data processing is automated  

## 🚀 Scripts
- `/scripts/generate_report.py` – Python automation script to generate report

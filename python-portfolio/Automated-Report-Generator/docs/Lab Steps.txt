Step 1 — Prepare Environment
- Install Python 3.8+ if not already installed
- Install required packages: pandas, matplotlib, reportlab
  Run: pip install pandas matplotlib reportlab
- Ensure folders exist: data/, charts/, reports/, screenshots/

Step 2 — Prepare Sample CSV(s)
- Place one or more CSV files in the data/ folder
- Example CSV columns: Date, Sales, Region
📸 Screenshot #1: CSV files in data/ folder (save in screenshots/01-csv.png)

Step 3 — Run Automation Script
- Open PowerShell and navigate to scripts/ folder
  cd "...\Automated-Report-Generator\scripts"
- Run script:
  python generate_report.py

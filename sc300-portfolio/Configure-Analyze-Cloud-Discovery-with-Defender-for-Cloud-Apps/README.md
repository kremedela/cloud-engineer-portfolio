# ☁️ Configure & Analyze Cloud Discovery with Microsoft Defender for Cloud Apps

## 🎯 Objective
This lab demonstrates how to configure **Cloud Discovery** in **Microsoft Defender for Cloud Apps (MDCA)** to discover, analyze, and manage shadow IT and SaaS applications in your environment.

By completing this lab, you will:
- Enable Cloud Discovery sensors
- Collect traffic logs from network devices and endpoints
- Analyze discovered applications
- Identify risky or unsanctioned apps
- Generate reports for governance and compliance

---

## 🧰 Tools & Services Used
- Microsoft Defender for Cloud Apps (MDCA)
- Cloud Discovery portal
- Network traffic logs / endpoint log collectors
- PowerShell for reporting

---

## 📝 Prerequisites
- Entra ID tenant
- Defender for Cloud Apps license
- Admin privileges in MDCA
- Sample traffic logs or test SaaS applications

---

## 🧪 Lab Steps (Summary)
1. Enable Cloud Discovery
2. Connect log sources (firewall, proxy, or endpoint)
3. Collect and upload traffic logs
4. Analyze discovered cloud apps
5. Identify risky applications
6. Generate reports and dashboards

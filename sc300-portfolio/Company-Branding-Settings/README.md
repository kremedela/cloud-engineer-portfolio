# Lab 06 – Configure Company Branding Settings

## 🎯 Objective
Learn how to configure Microsoft Entra company branding settings including logos, login page styling, background images, and user messaging. This lab teaches how organizations customize the sign-in experience for SSO, MFA, and tenant-wide identity consistency.

## 🧰 Azure Services Used
- Microsoft Entra ID
- Azure Portal
- Microsoft 365 (optional for cross-branding)
- Microsoft Graph PowerShell (optional)

## 📁 Folder Structure
- **docs/** – detailed walkthroughs  
- **scripts/** – PowerShell/Graph scripts  
- **screenshots/** – screenshots validating lab progress  

## 📝 Prerequisites
- Azure account  
- Global Administrator or Company Administrator role  
- Modern browser  
- Optional: corporate logo files (PNG recommended)

## 🧪 Lab Steps (Summary)
1. Review existing company branding configuration  
2. Upload login page banner, background, and logo  
3. Configure sign-in message and footer text  
4. Configure advanced branding: dark mode, language-specific pages  
5. Test login page branding in a private browser  
6. Update or remove branding if needed  

## ✅ Expected Outcome
- A fully branded Microsoft Entra sign-in experience  
- Login pages showing your organization’s logo, colors, and custom text  
- Ability to manage multiple branding configurations  
- Understanding of how branding applies to MFA, SSO, and MyApps portal  

## 🚀 Automation (Optional)
Use `/scripts/company-branding.ps1` to automate uploading and managing branding assets.

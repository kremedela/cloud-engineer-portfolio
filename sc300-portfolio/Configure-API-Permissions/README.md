# 🔑 Configure API Permissions in Microsoft Entra ID

## 🎯 Objective
This lab demonstrates how to **configure API permissions** for application registrations in Microsoft Entra ID. You will manage **delegated** and **application permissions** and grant admin consent to ensure secure access to APIs.

By completing this lab, you will:
- Understand app registration and permission types
- Configure delegated and application permissions
- Grant admin consent for enterprise applications
- Validate permission settings for security and functionality

---

## 🧰 Tools & Services Used
- Microsoft Entra ID
- App Registrations
- Enterprise Applications
- Microsoft Graph API
- Azure Portal

---

## 📝 Prerequisites
- Entra ID tenant
- Global Administrator or Application Administrator role
- Test application registration
- Optional: PowerShell 7 with Microsoft.Graph module

---

## 🧪 Lab Steps (Summary)
1. Register a test application
2. Configure delegated API permissions
3. Configure application permissions
4. Grant admin consent
5. Test permissions with API calls or token requests
6. Review enterprise app and audit logs

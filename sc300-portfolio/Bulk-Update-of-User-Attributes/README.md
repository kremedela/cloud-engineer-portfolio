# 🔄 Bulk Update of User Attributes in Microsoft Entra ID

## 🎯 Objective
This lab demonstrates how to **bulk update user attributes** in Microsoft Entra ID using automation. This scenario is common during reorganizations, mergers, role changes, and compliance initiatives.

By completing this lab, you will:
- Update user attributes at scale
- Use CSV-driven automation
- Modify attributes such as department, job title, and usage location
- Validate changes and audit activity

---

## 🧰 Tools & Services Used
- Microsoft Entra ID
- Microsoft Graph PowerShell
- Azure Cloud Shell (optional)
- CSV-based automation

---

## 📝 Prerequisites
- Entra ID tenant
- User Administrator or Global Administrator role
- Test users in Entra ID
- PowerShell 7 with Microsoft.Graph module installed

---

## 🧪 Lab Steps (Summary)
1. Prepare CSV file with user attributes
2. Connect to Microsoft Graph
3. Execute bulk update script
4. Validate updated attributes
5. Review audit logs

# Implement Authentication Methods

## 🎯 Objective
Learn how to plan, implement, and manage Microsoft Entra user authentication methods, including certificate-based authentication, temporary access pass, OAuth tokens, Microsoft Authenticator, and passkey (FIDO2).

## 🧰 Azure Services Used
- Microsoft Entra ID
- Azure Portal
- PowerShell / Graph API
- Microsoft 365 (if applicable)
- Conditional Access
- Identity Governance

## 📁 Folder Structure
- **docs/** – detailed walkthroughs, diagrams  
- **scripts/** – PowerShell/Graph scripts  
- **screenshots/** – images proving completion  

## 📝 Prerequisites
- Azure account  
- Global Administrator or Privileged Role Administrator  
- Modern browser  
- Test user accounts created in your tenant

## 🧪 Lab Steps (Summary)
1. Review and plan authentication methods.  
2. Enable and configure certificate-based authentication.  
3. Enable and configure temporary access passes.  
4. Configure Microsoft Authenticator registration.  
5. Configure passkey (FIDO2) authentication.  
6. Configure OAuth token settings.  
7. Test each authentication method using a test user account.

## ✅ Expected Outcome
- Multiple authentication methods configured in your tenant.  
- Test users able to sign in using the configured authentication methods.  
- Administrator can verify and manage all authentication methods centrally.

## 🚀 Automation (Optional)
PowerShell scripts or Graph API commands can be used to:
- Configure authentication methods for users
- Enable FIDO2 keys or temporary access passes
- Enforce MFA policies and settings

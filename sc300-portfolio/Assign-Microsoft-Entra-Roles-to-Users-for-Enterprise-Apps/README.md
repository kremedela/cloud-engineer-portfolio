# 🛂 Assign Microsoft Entra Roles to Users for Enterprise Apps

## 🎯 Objective
This lab demonstrates how to assign **Microsoft Entra ID directory roles** to users to manage and administer **enterprise applications** securely. It emphasizes role-based access control (RBAC), least privilege, and operational separation of duties—key concepts for SC-300 and enterprise IAM roles.

By completing this lab, you will:
- Assign Entra ID roles related to application management
- Scope administrative access to enterprise applications
- Validate role-based permissions and boundaries
- Demonstrate secure delegation of administrative responsibilities

---

## 🧰 Tools & Services Used
- Microsoft Entra ID
- Entra ID Roles and Administrators
- Enterprise Applications
- Microsoft Entra Admin Center
- PowerShell (Microsoft Graph)

---

## 📝 Prerequisites
- Entra ID tenant
- Global Administrator role
- Enterprise application already created
- Test users available for role assignment
- PowerShell 7 with Microsoft.Graph module installed

---

## 🧪 Lab Steps (Summary)
1. Review available Entra ID roles
2. Assign application-related roles to users
3. Validate permissions for enterprise app management
4. Test role-based access boundaries
5. Review audit and role assignment logs

# 🌐 Configure External Identity Providers in Microsoft Entra ID

## 🎯 Objective
This lab demonstrates how to **configure external identity providers** (IdPs) in Microsoft Entra ID for secure B2B and B2C access. You will integrate with external IdPs using **SAML or OpenID Connect** and manage user access and authentication.

By completing this lab, you will:
- Configure external identity providers for federation
- Enable secure access for guest and external users
- Validate authentication flows
- Ensure compliance and governance for external identities

---

## 🧰 Tools & Services Used
- Microsoft Entra ID
- External Identity Providers (SAML, OIDC)
- Azure B2B/B2C
- Enterprise Applications
- Azure Portal
- Optional: PowerShell / Microsoft Graph

---

## 📝 Prerequisites
- Entra ID tenant
- Global Administrator or External IdP Admin role
- Test external identity provider
- Test user accounts (internal and external)

---

## 🧪 Lab Steps (Summary)
1. Configure an external identity provider in Entra ID
2. Set up trust and claims mapping
3. Enable B2B/B2C access for test users
4. Assign access to enterprise apps
5. Validate authentication for external users
6. Review audit and sign-in logs

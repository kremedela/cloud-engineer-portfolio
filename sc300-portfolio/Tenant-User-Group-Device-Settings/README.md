# Lab 07 – Configure Tenant Properties, User Settings, Group Settings, and Device Settings

## 🎯 Objective
Learn how to configure core Microsoft Entra tenant-wide settings including tenant branding, user permissions, group lifecycle policies, and device governance. This lab teaches real-world identity configuration tasks that are essential for security, compliance, and Zero Trust administration.

## 🧰 Azure Services Used
- Microsoft Entra ID
- Azure Portal
- Conditional Access  
- Microsoft Graph PowerShell  
- Identity Governance (optional)

## 📁 Folder Structure
- **docs/** – detailed walkthroughs  
- **scripts/** – PowerShell/Graph scripts  
- **screenshots/** – screenshots validating results

## 📝 Prerequisites
- Azure account  
- Global Administrator or Identity Administrator  
- Modern browser  

## 🧪 Lab Steps (Summary)
1. Review tenant information  
2. Configure tenant properties  
3. Configure user settings  
4. Configure group settings  
5. Configure device settings  
6. Validate all changes with a test user and test device

## ✅ Expected Outcome
- Tenant properties configured and aligned with organizational requirements  
- User settings updated to enforce secure collaboration and feature control  
- Group settings optimized for lifecycle & naming policies  
- Device settings enforcing secure device join and registration  
- Test user and test device validated against policy

## 🚀 Automation (Optional)
Use `/scripts/tenant-settings.ps1` to automate viewing and modifying tenant, user, group, and device policies.

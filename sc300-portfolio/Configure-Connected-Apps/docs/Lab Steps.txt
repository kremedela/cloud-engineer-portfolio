============================================================
SC-300 — Configure Connected Applications
Full Detailed Instructions
============================================================

------------------------------------------------------------
Step 1 — Identify Connected Applications
------------------------------------------------------------
1. Navigate to Entra Admin Center → Enterprise Applications
2. List all connected applications
3. Review security and SSO settings

📸 Screenshot: /screenshots/01-connected-apps.png

------------------------------------------------------------
Step 2 — Configure Single Sign-On (SSO)
------------------------------------------------------------
1. Select the target application
2. Go to Single sign-on → SAML or OIDC
3. Configure required parameters (Identifier, Reply URL, Claims)
4. Save settings

📸 Screenshot: /screenshots/02-sso-configuration.png

------------------------------------------------------------
Step 3 — Assign Users and Groups
------------------------------------------------------------
1. Navigate to Users and Groups
2. Assign internal users or groups
3. Optionally assign guest users
4. Verify assignment status

📸 Screenshot: /screenshots/03-user-group-assignment.png

------------------------------------------------------------
Step 4 — Configure Claims and Attributes
------------------------------------------------------------
1. Go to Attributes & Claims
2. Map required attributes (e.g., UPN, email)
3. Save and test claims

📸 Screenshot: /screenshots/04-claims-attributes.png

------------------------------------------------------------
Step 5 — Validate App Connectivity
------------------------------------------------------------
1. Test login for assigned users
2. Verify SSO works as expected
3. Check tokens/claims for correctness

📸 Screenshot: /screenshots/05-app-authentication.png

------------------------------------------------------------
Step 6 — Review Audit Logs
------------------------------------------------------------
1. Navigate to Entra ID → Audit Logs
2. Filter by application
3. Confirm assignments, SSO events, and authentication attempts

📸 Screenshot: /screenshots/06-audit-logs.png

------------------------------------------------------------
End of Lab
============================================================

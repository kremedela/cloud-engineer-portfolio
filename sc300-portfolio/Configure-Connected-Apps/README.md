# 🔗 Configure Connected Applications in Microsoft Entra ID

## 🎯 Objective
This lab demonstrates how to **manage connected applications** in Microsoft Entra ID, including **SSO configuration, permissions, and security settings** to ensure secure access across your enterprise environment.

By completing this lab, you will:
- Review connected applications
- Configure SSO for enterprise apps
- Manage app permissions and claims
- Ensure security best practices for app connections

---

## 🧰 Tools & Services Used
- Microsoft Entra ID
- Enterprise Applications
- App Registrations
- SSO (SAML/OIDC)
- Azure Portal
- Optional: PowerShell / Microsoft Graph

---

## 📝 Prerequisites
- Entra ID tenant
- Global Administrator or Application Administrator role
- Test applications (internal or SaaS)
- Optional: PowerShell 7 with Microsoft.Graph module

---

## 🧪 Lab Steps (Summary)
1. Identify connected applications in Entra ID
2. Configure SSO for enterprise apps
3. Assign users and groups
4. Configure claims and attributes
5. Validate app connectivity and authentication
6. Review audit logs for compliance

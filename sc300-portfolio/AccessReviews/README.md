# 🔐 Access Reviews

## 🎯 Objective
This lab demonstrates how to configure and manage **Access Reviews** in Microsoft Entra ID to ensure users maintain only the access they need. It aligns with Zero Trust and least-privilege principles and is a core skill tested in the SC-300 certification.

By completing this lab, you will:
- Configure access reviews for groups and applications
- Validate reviewer workflows
- Automate removal of unnecessary access
- Demonstrate identity governance capabilities

---

## 🧰 Tools & Services Used
- Microsoft Entra ID (Azure AD)
- Identity Governance
- Access Reviews
- Microsoft Entra Admin Center
- PowerShell (Microsoft Graph)

---

## 📝 Prerequisites
- Entra ID tenant with Identity Governance enabled
- Global Administrator or Identity Governance Administrator role
- Test users and security groups created
- PowerShell 7 with Microsoft.Graph module installed

---

## 🧪 Lab Steps (Summary)
1. Identify users and groups for review
2. Create an access review for a security group
3. Configure reviewers and review schedule
4. Perform access review as reviewer
5. Apply automated remediation
6. Validate access removal

---

## 📸 Screenshot Guidance
- Access Review configuration summary
- Reviewer approval/deny screen
- Completed access review results
- User access removed from group

---

## 🚀 Expected Outcome
- Access reviews successfully configured and completed
- Unnecessary access automatically removed
- Clear demonstration of identity governance and compliance readiness

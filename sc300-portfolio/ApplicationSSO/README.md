# 🔑 Application Single Sign-On (SSO)

## 🎯 Objective
This lab demonstrates how to configure **Single Sign-On (SSO)** for enterprise applications using Microsoft Entra ID as the Identity Provider (IdP). It focuses on modern authentication protocols aligned with Zero Trust principles and SC-300 requirements.

By completing this lab, you will:
- Configure SSO for an enterprise application
- Implement SAML or OpenID Connect authentication
- Assign users and groups to applications
- Validate authentication and access flows

---

## 🧰 Tools & Services Used
- Microsoft Entra ID
- Enterprise Applications
- SAML / OpenID Connect (OIDC)
- Microsoft Entra Admin Center
- Test SaaS or gallery application

---

## 📝 Prerequisites
- Entra ID tenant
- Global Administrator or Application Administrator role
- Test users and security groups created
- Access to an enterprise application (gallery or custom)

---

## 🧪 Lab Steps (Summary)
1. Add an enterprise application
2. Configure SSO (SAML or OIDC)
3. Assign users or groups
4. Test SSO authentication
5. Validate claims and sign-in logs

- Enterprise application overview

## 🚀 Expected Outcome
- Application SSO successfully configured
- Users authenticate using Entra ID credentials
- Authentication logs confirm secure access
- Demonstrates real-world enterprise SSO configuration

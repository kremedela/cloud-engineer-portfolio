# ✅ Configure and Manage User and Admin Consent in Microsoft Entra ID

## 🎯 Objective
This lab demonstrates how to **manage user and admin consent** for applications in Microsoft Entra ID, ensuring that applications only request appropriate permissions and users approve only allowed scopes.

By completing this lab, you will:
- Configure consent settings for applications
- Enable or restrict user consent
- Review admin consent requirements
- Validate consent flows for users and applications

---

## 🧰 Tools & Services Used
- Microsoft Entra ID
- App Registrations
- Enterprise Applications
- User & Admin Consent Settings
- Azure Portal
- Optional: PowerShell / Microsoft Graph

---

## 📝 Prerequisites
- Entra ID tenant
- Global Administrator or Privileged Role Administrator role
- Test applications with delegated permissions
- Test user accounts (internal and guest)

---

## 🧪 Lab Steps (Summary)
1. Review app permission requests
2. Configure user consent settings
3. Configure admin consent settings
4. Assign required roles for consent approval
5. Validate user and admin consent flows
6. Audit consent approvals

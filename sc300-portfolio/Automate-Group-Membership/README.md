# 🔄 Automate Group Membership in Microsoft Entra ID

## 🎯 Objective
This lab demonstrates how to **automate group membership** in Microsoft Entra ID using **dynamic group rules**. Automating group membership ensures consistent access control, supports least privilege, and simplifies identity lifecycle management.

By completing this lab, you will:
- Create dynamic user groups in Entra ID
- Define rule-based membership conditions
- Validate automatic user assignment and removal
- Demonstrate scalable access management aligned with SC-300 objectives

---

## 🧰 Tools & Services Used
- Microsoft Entra ID
- Dynamic Groups
- Entra ID Users & Groups
- Microsoft Entra Admin Center
- PowerShell (Microsoft Graph)

---

## 📝 Prerequisites
- Entra ID tenant
- Global Administrator or Groups Administrator role
- Users with defined attributes (department, jobTitle, or country)
- PowerShell 7 with Microsoft.Graph module installed

---

## 🧪 Lab Steps (Summary)
1. Review user attributes for dynamic rules
2. Create a dynamic security group
3. Configure rule-based membership
4. Validate automated group assignments
5. Monitor membership changes

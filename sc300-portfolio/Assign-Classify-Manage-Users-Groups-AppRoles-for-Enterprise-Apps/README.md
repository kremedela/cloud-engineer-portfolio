# 👥 Assign, Classify & Manage Users, Groups, and App Roles for Enterprise Apps

## 🎯 Objective
This lab demonstrates how to assign and manage **users, groups, and application roles** for enterprise applications in Microsoft Entra ID. It focuses on role-based access control (RBAC), least privilege, and scalable access management—key skills for SC-300 and enterprise IAM roles.

By completing this lab, you will:
- Assign users and groups to enterprise applications
- Configure and manage application roles
- Classify access based on role and function
- Validate role-based access enforcement

---

## 🧰 Tools & Services Used
- Microsoft Entra ID
- Enterprise Applications
- App Roles
- Entra ID Groups
- Microsoft Entra Admin Center
- PowerShell (Microsoft Graph)

---

## 📝 Prerequisites
- Entra ID tenant
- Global Administrator or Application Administrator role
- Enterprise application configured (SSO enabled)
- Test users and security groups created

---

## 🧪 Lab Steps (Summary)
1. Review enterprise application configuration
2. Create and define application roles
3. Assign users and groups to the application
4. Map users/groups to specific app roles
5. Validate access behavior

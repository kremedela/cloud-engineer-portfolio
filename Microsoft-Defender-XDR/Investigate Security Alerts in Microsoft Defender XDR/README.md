# Investigate Security Alerts in Microsoft Defender XDR

## 🎯 Objective
Learn how to review, analyze, and respond to security alerts generated by Microsoft Defender XDR. This lab focuses on real-world SOC workflows such as alert triage, severity validation, entity analysis, and determining appropriate response actions across endpoints, identities, email, and cloud apps.

## 🧰 Microsoft Services Used
- Microsoft Defender XDR
- Microsoft Defender for Endpoint
- Microsoft Defender for Office 365
- Microsoft Entra ID
- Microsoft 365 Security Portal
- Microsoft Graph PowerShell

## 📁 Folder Structure
- **docs/** – Full step-by-step lab instructions
- **scripts/** – PowerShell script to export Defender alerts
- **screenshots/** – Evidence of alert investigation and response

## 📝 Prerequisites
- Microsoft 365 tenant with Defender XDR enabled
- At least one onboarded endpoint in Defender for Endpoint
- Security Reader, Security Operator, or Security Administrator role
- Sample alerts available (or test alert generated)

## 🧪 Lab Steps (Summary)
1. Review active security alerts in Defender XDR
2. Analyze alert severity, category, and MITRE mapping
3. Investigate affected entities (users, devices, mailboxes)
4. Review alert timeline and evidence
5. Determine and document response action
6. Export alerts using PowerShell for reporting

## ✅ Expected Outcome
- Ability to triage Defender XDR alerts effectively
- Understanding how alerts correlate across security workloads
- Confidence determining false positives vs true threats
- Ability to export alerts for reporting and analysis

## 🚀 Optional Automation
Use `/scripts/defender-alert-report.ps1` to export recent Defender XDR alerts into a CSV report for SOC review or documentation.

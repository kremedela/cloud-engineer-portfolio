# 🎨 Create Canvas App from Data

## 🎯 Objective  
Build a basic Canvas App by connecting to a data source (Dataverse, SharePoint, Excel, or SQL) and auto-generating screens.

---

## 🧩 Lab Structure  
1. Connect to data source  
2. Generate a Canvas App  
3. Explore screens  
4. Add edits, search, and sort  
5. Test the app  
6. Publish and share  

---

## 📘 Summary of Lab Steps  
- Create a new Canvas App  
- Select a data source  
- Auto-generate screens from the table  
- Modify UI components  
- Test and validate  
- Publish the final app  

---

## ✅ Prerequisites  
- Power Apps license  
- Access to Dataverse OR a SharePoint list OR an Excel file in OneDrive  
- Maker permissions in the environment  

---

## 🛠️ Tools & Services Used  
- Power Apps  
- Dataverse / SharePoint / Excel / SQL  
- Power Apps Studio  

---

## 🏁 Expected Outcome  
A functional Canvas App with autogenerated Browse, Detail, and Edit screens connected to live data.

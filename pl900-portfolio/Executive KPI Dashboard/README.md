# Executive KPI Dashboard

## 🎯 Objective
Create an executive-level Power BI dashboard that visualizes high-impact business KPIs such as Revenue, Profit, Margin %, YOY Growth, and regional or customer performance insights. This dashboard will help leadership quickly understand organizational performance.

## 🧱 Lab Structure
1. Load and prepare financial, sales, and customer datasets  
2. Build a star-schema data model  
3. Create KPI measures using DAX  
4. Build dashboard visuals  
5. Add slicers, interactivity, drill-through, and tooltips  
6. Format and optimize the report  
7. Publish to Power BI Service and configure governance  

## 📝 Summary of Lab Steps
- Import data sources (Finance, Sales, Date, Customer, Region)  
- Build model relationships and mark the date table  
- Create DAX measures (Revenue, Profit, YOY Growth, Margin %)  
- Build KPI cards and executive visuals  
- Add slicers and drill-through pages  
- Apply visual formatting and optimize model  
- Publish to Power BI workspace  

## 📌 Prerequisites
- Power BI Desktop installed  
- Sample datasets (Finance, Sales, Date, Customer, Region)  
- Power BI Pro or PPU license to publish  
- Workspace permissions  

## 🛠️ Tools & Services Used
- Power BI Desktop  
- Power BI Service  
- DAX for KPI calculation  
- Power Query  

## ✅ Expected Outcome
You will create a fully-functional Executive KPI Dashboard that includes core financial metrics, customer insights, performance trends, and interactivity that leadership can use to make data-driven decisions.

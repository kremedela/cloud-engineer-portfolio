---

## ✅ Step 2 — Create Azure AD App Registration
1. Go to Azure Portal → **Azure AD → App Registrations**
2. Create app:
- Name: **PP-ALM-SPN**
- Accounts: Single tenant
3. Generate:
- **Client ID**
- **Client Secret**
4. Add API permissions:
- Power Platform Service (Delegate + Application)
5. Assign to Power Platform roles:
- **Environment Maker**
- **System Administrator (Dev/Test/Prod)**

---

## ✅ Step 3 — Add GitHub Secrets
In the GitHub repo:
- `CLIENT_ID`
- `CLIENT_SECRET`
- `TENANT_ID`
- `DEV_ENV_URL`
- `TEST_ENV_URL`
- `PROD_ENV_URL`
- `SOLUTION_NAME`

## ✅ Step 8 — Run Initial Export
1. Push a commit to `main`
2. GitHub Action automatically:
   - Authenticates with PAC CLI  
   - Exports solution from Dev  
   - Unpacks solution  
   - Commits the changes  

---

## ✅ Step 9 — Test Deployment Pipeline
To publish new changes:

1. Modify solution in Dev  
2. Push trigger file `deploy.yml` with:
   - New version  
3. GitHub Action:
   - Packs solution  
   - Imports to Test (managed)
   - Imports to Prod (managed)

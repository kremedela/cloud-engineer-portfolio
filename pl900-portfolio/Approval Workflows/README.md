# Approval Workflows

## 🎯 Lab Objective
Build a complete approval workflow using Power Automate. You will create a request form, trigger an approval, notify approvers, log decisions, and store outcomes in Dataverse or SharePoint.

## 🧩 Skills Learned
- Building automated approval processes
- Using Start and Wait for an Approval
- Customizing approval messages
- Adding conditional branches (Approve/Deny)
- Saving approval history to Dataverse or SharePoint
- Sending notifications and confirmation emails

## 📦 Lab Structure
1. Create a data source (Dataverse/SharePoint)
2. Build an approval flow
3. Configure approval options
4. Add conditional branching
5. Log approval outcome
6. Notify the requester

## 📝 Summary of Lab Steps
- Prepare a data table for requests  
- Build a Power Automate approval flow  
- Add actions for approval decision handling  
- Save approval results  
- Test the workflow end-to-end  

## 🔧 Tools and Services Used
- Power Automate  
- Dataverse or SharePoint  
- Power Apps (optional for form UI)  
- Approval Connector (built-in)

## ✔️ Expected Outcome
A fully working approval workflow that:
- Sends approval requests  
- Handles approve/deny responses  
- Logs results into a data source  
- Sends automated notifications

# Dataverse RBAC (Role-Based Access Control)

## 🎯 Lab Objective
Learn how to configure Dataverse security using **roles, business units, and team assignments** to restrict or grant access to tables and data.

## 🧩 Skills Learned
- How Dataverse RBAC works  
- Creating and assigning **security roles**  
- Business Units and hierarchy  
- Table-level and record-level permissions  
- Team-based sharing models  

## 📦 Deliverables
- A new **custom security role**
- A configured **Business Unit**
- A security model implemented using:
  - Row-level permissions
  - Table permissions
  - User/Team assignment

## 🔧 Tools Used
- Power Apps Admin Center  
- Dataverse Security Roles  
- Power Platform Admin Portal  

## 📝 Short Summary of Lab Steps
1. Create a new Business Unit  
2. Create a new Dataverse Security Role  
3. Set table permissions on the custom role  
4. Assign role to a user  
5. (Optional) Create a team & assign security role  
6. Test access using role + BU structure

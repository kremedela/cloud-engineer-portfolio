# 📁 Dataverse Table Creation

## 🎯 Objective  
Create a new Dataverse table, define columns, configure relationships, and populate it with sample data.

---

## 🧩 Lab Structure  
1. Create a new table in Dataverse  
2. Add standard and custom columns  
3. Configure keys and relationships  
4. Add data manually or import sample data  
5. View table in Data Experience  
6. Use table in a Canvas App (optional)  

---

## 📘 Summary of Lab Steps  
- Navigate to the Power Apps Maker Portal  
- Create a new Dataverse table  
- Add fields with proper data types  
- Create table relationships  
- Add sample data rows  
- Validate the table schema  

---

## 📑 Prerequisites  
- Power Apps license (Per-user, Per-app, or Developer plan)  
- Environment with Dataverse enabled  
- Access to Power Apps Maker Portal  
- Basic understanding of data modeling  

---

## 🛠️ Tools & Services Used  
- Power Apps Maker Portal  
- Dataverse  
- Table designer  
- Data editor/import wizard  

---

## 🏁 Expected Outcome  
You will have a fully functional Dataverse table with custom fields, relationships, and data ready for use in apps, flows, and dashboards.

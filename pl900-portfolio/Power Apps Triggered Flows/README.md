# Power Apps Triggered Flows

## 🎯 Lab Objective
Learn how to build Power Automate flows that start directly from a Power App button, pass user inputs into the flow, and return results to the app.

## 🧩 Skills Learned
- Building instant cloud flows triggered from Power Apps
- Passing parameters from Power Apps to the flow
- Returning values from the flow back to the app
- Using actions like Compose, Variables, Dataverse, and Email

## 📦 Lab Structure
1. Create an Instant Flow triggered by Power Apps  
2. Add input parameters  
3. Perform operations inside the flow  
4. Send responses back to Power Apps  
5. Connect the flow to a Power App button

## 📝 Summary of Lab Steps
- Create Power Apps trigger flow  
- Add parameters (e.g., user text)  
- Add business logic  
- Return results  
- Trigger the flow from a Power App  

## 🔧 Tools and Services Used
- Power Apps (Canvas App)
- Power Automate (Cloud Flows)
- Dataverse (optional)
- Email or Teams connector (optional)

## ✔️ Expected Outcome
A working Power App button that calls a Power Automate flow, performs actions, and returns a value displayed inside the app.

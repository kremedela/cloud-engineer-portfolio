# Custom Connector Creation

## 🎯 Objective
Create a Custom Connector that communicates with an external REST API, defines operations, imports schemas, and can be used inside Power Automate and Power Apps.

## 🧠 Skills Learned
- Creating a Custom Connector from scratch  
- Configuring API host, base URL, and authentication  
- Importing request/response schemas  
- Defining actions  
- Testing custom connectors  
- Consuming connectors inside Power Automate  

## 📌 Prerequisites
- Power Apps or Power Automate environment  
- Basic understanding of REST APIs  
- Sample API to call (JSONPlaceholder used in this lab)  

## 🏗 Architecture Overview
**Power Automate / Power Apps → Custom Connector → External REST API (JSONPlaceholder)**  
This lab walks you through configuring the connector and integrating it into a flow.

## 📝 Short Summary of Lab Steps
1. Choose the API (JSONPlaceholder).  
2. Create a new custom connector from blank.  
3. Configure general settings (host, base URL).  
4. Set authentication (none for this API).  
5. Add an action and import request/response.  
6. Test the custom connector.  
7. Use the connector inside a Power Automate flow.  

## 📦 Deliverables
- Fully working Custom Connector  
- Successful API test call  
- Flow demonstrating connector usage

# Connector Integrations

## 🎯 Lab Objective
Learn how to integrate external data sources and services into Power Apps and Power Automate using connectors (standard + premium). Configure connections, test API calls, and use connector actions inside apps and flows.

## 🧩 Skills Learned
- Understanding connector types (standard vs. premium)
- Authenticating connectors
- Using connectors in Canvas Apps
- Using connectors inside Power Automate flows
- Common connector patterns (POST, GET, LIST, FILTER, CREATE)
- Error handling and connection validation

## 📦 Deliverables
- Successfully configured connections
- A basic app using a connector
- A Power Automate flow using at least one connector
- Demonstrated successful API call

## 🔧 Tools Used
- Power Apps Maker Portal  
- Power Automate  
- Common connectors (Office 365, Outlook, Teams, Excel, SharePoint, HTTP connector)

## 📝 Short Summary of Lab Steps
1. Create a new connection  
2. Test connector authentication  
3. Use a connector inside Power Apps  
4. Use a connector inside Power Automate  
5. Test the end-to-end workflow  
6. Validate data flow and output

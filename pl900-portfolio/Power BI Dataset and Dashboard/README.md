# 📊 Power BI Dataset and Dashboard

## 🎯 Objective  
Learn how to create a Power BI dataset from a data source, build a report, and publish a dashboard to the Power BI Service.

---

## 🧩 Lab Structure  
1. Prepare data source  
2. Load data into Power BI Desktop  
3. Clean and transform data in Power Query  
4. Build visuals and reports  
5. Publish to Power BI Service  
6. Create a dashboard and pin tiles  
7. Share dashboard  

---

## 📘 Summary of Lab Steps  
- Import data into Power BI Desktop  
- Transform and model the dataset  
- Create visuals (tables, charts, KPIs)  
- Publish report to Power BI Service  
- Pin visuals to dashboard  
- Share dashboard with users  

---

## ✅ Prerequisites  
- Power BI Desktop installed  
- Power BI Pro or PPU license  
- Access to Power BI Service  
- Test dataset (CSV, Excel, SharePoint list, or Dataverse table)

---

## 🛠️ Tools & Services Used  
- Power BI Desktop  
- Power BI Service  
- Power Query Editor  
- Dataset & report publishing  
- Dashboard creation  

---

## 🏁 Expected Outcome  
You will build and publish a fully functional Power BI dataset, report, and dashboard that can be shared with others.

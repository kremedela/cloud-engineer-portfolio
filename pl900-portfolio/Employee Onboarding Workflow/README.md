# Employee Onboarding Workflow

## 🎯 Objective  
Build an automated employee onboarding workflow using Power Automate, SharePoint, and Dataverse that orchestrates tasks, notifications, and approvals across HR and IT teams.

## 🧱 Lab Structure  
- Part 1 — Create onboarding data source  
- Part 2 — Build automated onboarding flow  
- Part 3 — Add approval step for HR  
- Part 4 — Create tasks for IT and Facilities  
- Part 5 — Test end-to-end onboarding process  

## 📝 Summary of Lab Steps  
1. Create a SharePoint list or Dataverse table to store onboarding data.  
2. Build a Power Automate flow triggered when a new employee record is created.  
3. Add HR approval step.  
4. Generate task lists for IT/FAC teams.  
5. Send welcome and provisioning notifications.  
6. Validate the workflow with test data.

## 📦 Prerequisites  
- Power Automate license  
- Access to SharePoint or Dataverse  
- HR/IT email accounts for testing  
- Power Platform environment  

## 🔧 Tools and Services Used  
- Power Automate  
- SharePoint OR Dataverse  
- Outlook Connector  
- Microsoft Teams (optional notifications)  

## ✅ Expected Outcome  
A fully automated onboarding workflow that routes requests, collects approvals, creates tasks, and sends onboarding notifications to stakeholders.

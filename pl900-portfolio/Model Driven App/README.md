# Model Driven App

## 🎯 Lab Objective
Build a fully functional **Model-Driven App** using Dataverse tables, views, dashboards, and forms to enable structured business workflows.

## 🧩 Skills Learned
- Designing a model-driven app
- Using Dataverse tables as the backbone
- Creating site maps, navigation, and views
- Adding forms, charts, dashboards
- Securing the app using roles

## 📦 Deliverables
- A new Model-Driven App
- Custom navigation (sitemap)
- Configured views + forms
- Secured access via the security role created in Lab 5

## 🔧 Tools Used
- Power Apps Maker Portal
- Dataverse
- Security roles (from Lab 5)

## 📝 Short Summary of Lab Steps
1. Create new Model-Driven App  
2. Add Dataverse tables  
3. Configure sitemap navigation  
4. Modify views and forms  
5. Add dashboards & charts  
6. Publish the app  
7. Secure the app using Dataverse RBAC

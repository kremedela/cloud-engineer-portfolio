# Power Apps Portal Basics

## 🎯 Lab Objective
Create a basic Power Apps Portal (Power Pages site), customize pages, configure authentication, and surface Dataverse data on the public-facing site.

## 🧩 Skills Learned
- Creating a Power Apps Portal (Power Pages website)
- Editing pages with the Power Pages design studio
- Configuring site authentication (Azure AD, local login)
- Connecting Dataverse tables to portal pages
- Creating forms and lists for external users

## 📦 Lab Structure
1. Create a Power Apps Portal (Power Pages site)
2. Configure permissions and security roles
3. Add and edit web pages
4. Create a Dataverse form and list for data display
5. Test the portal externally

## 📝 Summary of Lab Steps
- Provision the portal  
- Configure table permissions  
- Add web pages and components  
- Build forms/lists from Dataverse  
- Publish and test the site  

## 🔧 Tools and Services Used
- Power Pages (formerly Power Apps Portals)
- Microsoft Dataverse
- Power Apps Maker Portal
- Azure AD (optional authentication)

## ✔️ Expected Outcome
A functioning Power Pages portal that:
- Displays web content  
- Shows Dataverse data  
- Allows authenticated users to submit data  
- Is accessible via a public-facing URL

# Automated Document Generation

## 🎯 Objective
Automatically generate documents (PDF, Word, or Excel) using Power Automate and pre-built templates. This lab simulates creating dynamic reports, invoices, onboarding packets, or standardized business documents.

## 🧱 Lab Structure
1. Prepare a Word template with dynamic placeholders  
2. Create a Power Automate flow that populates the template  
3. Store generated documents in OneDrive or SharePoint  
4. Trigger the flow manually or automatically  
5. Validate generated documents  

## 📝 Summary of Lab Steps
- Create a Word template with content controls  
- Upload it to SharePoint or OneDrive  
- Build a Power Automate flow using "Populate Word Template"  
- Generate a document dynamically  
- Save to SharePoint/OneDrive and test the output  

## 📌 Prerequisites
- Power Automate license  
- Word Template (.docx) with content controls  
- SharePoint or OneDrive document library  
- Basic user permissions to create a flow  

## 🛠️ Tools & Services Used
- Power Automate  
- Microsoft Word  
- SharePoint / OneDrive  
- Dynamic content mapping  

## ✅ Expected Outcome
You will have an automated system that produces a dynamic, fully formatted document based on user input, form data, or system data—ready for distribution, compliance, or reporting.

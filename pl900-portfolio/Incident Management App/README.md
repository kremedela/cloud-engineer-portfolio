## 📛 Incident Management App

## 🎯 Objective  
Build a functional Incident Management application using Power Apps, Dataverse, and Power Automate to track, update, and automate incident tickets.

## 🧱 Lab Structure  
- Part 1 — Create Dataverse tables  
- Part 2 — Build Canvas App interface  
- Part 3 — Add automation with Power Automate  
- Part 4 — Test and validate workflow  

## 📝 Summary of Lab Steps  
1. Create Dataverse tables (Incidents + Categories + Statuses).  
2. Build a Canvas App using the new tables.  
3. Add forms, galleries, and incident detail screens.  
4. Create a Power Automate flow to send notifications.  
5. Test creating and updating incidents in the app.

## 📦 Prerequisites  
- Environment with Dataverse enabled  
- Power Apps license  
- Power Automate license  
- Access to Power Platform Admin Center  

## 🔧 Tools and Services Used  
- Power Apps (Canvas App)  
- Power Automate  
- Dataverse  
- Email notifications (Outlook connector)

## ✅ Expected Outcome  
You will have a fully functional Incident Management App with automation that tracks new incidents, updates status, and sends alerts.

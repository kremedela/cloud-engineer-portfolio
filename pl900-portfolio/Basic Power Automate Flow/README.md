# 🔁 Basic Power Automate Flow

## 🎯 Objective  
Create an automated cloud flow that triggers on a specific event (new item, new email, form submission, etc.) and performs a basic action such as sending an email or writing to a list.

---

## 🧩 Lab Structure  
1. Choose a trigger  
2. Create a new cloud flow  
3. Add an action  
4. Configure dynamic content  
5. Test the flow  
6. Check run history  
7. Enable/disable the flow  

---

## 📘 Summary of Lab Steps  
- Create new automated cloud flow  
- Select a trigger (e.g., “When an item is created”)  
- Add an action (send email, update row, create row)  
- Map dynamic fields  
- Test flow end-to-end  
- Verify logs and correct errors  

---

## ✅ Prerequisites  
- Power Automate license  
- Access to SharePoint, Dataverse, or Outlook (depending on trigger)  
- Maker permissions  

---

## 🛠️ Tools & Services Used  
- Power Automate  
- SharePoint / Dataverse / Outlook  
- Flow Checker  

---

## 🏁 Expected Outcome  
A working automated cloud flow that triggers from a real event and performs a business action automatically.

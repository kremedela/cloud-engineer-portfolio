# Review and Respond to Security Reports in Microsoft Defender XDR

## 🎯 Objective
Learn how to monitor, review, and respond to security reports generated by Microsoft Defender XDR, including interpreting alerts, prioritizing threats, and taking appropriate remediation actions.

## 🧰 Azure Services Used
- Microsoft 365 Defender Portal  
- Microsoft Defender XDR  
- Microsoft 365 Admin Center  
- PowerShell / Graph API (optional)

## 📁 Folder Structure
- **docs/** – detailed walkthroughs, diagrams  
- **scripts/** – PowerShell/Graph scripts  
- **screenshots/** – images proving completion  

## 📝 Prerequisites
- Microsoft 365 E5 tenant with Defender XDR enabled  
- Security Administrator or Global Administrator role  
- Test users and devices generating sample alerts  

## 🧪 Lab Steps (Summary)
- Access the Microsoft 365 Defender dashboard  
- Review security reports and prioritize alerts  
- Analyze affected users, devices, and attack vectors  
- Take remediation actions (quarantine, reset accounts, block threats)  
- Document findings and export reports  
- Optional automation via PowerShell to query alerts  

## ✅ Expected Outcome
- Accessed and navigated Defender XDR dashboard  
- Reviewed and responded to security alerts  
- Remediated threats effectively  
- Documented reports for auditing purposes  

## 🚀 Optional Automation
- PowerShell / Graph API scripts to list recent alerts and mark them resolved
